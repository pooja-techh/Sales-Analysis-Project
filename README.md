# Sales Analytics Project

## Project Overview

This project analyzes sales data to understand business performance, sales trends, profit, products, countries, and customer segments.

## Objective

The main objective of this project is to clean, analyze, and visualize sales data and identify useful business insights.

## Dataset

The dataset contains 700 sales records with information about:

- Segment
- Country
- Product
- Units Sold
- Manufacturing Price
- Sale Price
- Gross Sales
- Discounts
- Sales
- COGS
- Profit
- Date
- Year

## Tools Used

- Python
- Pandas
- Matplotlib
- VS Code
- Microsoft Excel / Apple Numbers
- Power BI-style dashboard

## Analysis Performed

The project includes:

- Data cleaning
- Missing value analysis
- Sales analysis
- Profit analysis
- Sales by country
- Sales by product
- Sales by segment
- Year-wise sales analysis
- Data visualization
- Business insights

## Key Results

- Total Sales: $118,726,350.26
- Total Profit: $16,893,702.26
- Total Units Sold: 1,125,806
- Profit Margin: 14.23%
- Number of Records: 700
- Number of Products: 6
- Number of Countries: 5

## Key Business Insights

1. Sales increased significantly from 2013 to 2014.
2. The United States generated the highest total sales.
3. Government was the strongest profit-generating segment.
4. Enterprise was the only segment with negative profit.
5. Paseo was the highest-selling product.
6. The overall profit margin was 14.23%.

## Project Files

- `analysis.py` - Python analysis code
- `sales_data.csv` - Dataset
- `PowerBI_Sales_Dashboard_Alternative.xlsx` - Dashboard
- `PowerBI_Sales_Dashboard_Report.pdf` - Final report

## Conclusion

The analysis shows strong overall sales and profitability, with Government and Small Business segments contributing significantly to profit. The Enterprise segment requires further investigation because of its negative profitability.

This project demonstrates the use of Python, Pandas, data visualization, Excel/Numbers, and dashboard-based business analysis.
